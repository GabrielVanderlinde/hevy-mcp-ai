# Changesets

Esta pasta foi gerada automaticamente pelo `@changesets/cli`, uma ferramenta para gerenciar versões e publicações em repositórios com um ou vários pacotes.

A ferramenta ajuda a registrar alterações, preparar versões e manter o histórico de publicação organizado.

- [Documentação oficial do Changesets](https://github.com/changesets/changesets)
- [Perguntas frequentes](https://github.com/changesets/changesets/blob/main/docs/common-questions.md)

Antes de alterar os arquivos desta pasta, consulte a documentação oficial para entender o fluxo esperado.
