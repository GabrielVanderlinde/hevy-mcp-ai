# Hevy MCP — Integração com assistentes de IA

Este repositório é um fork de [chrisdoc/hevy-mcp](https://github.com/chrisdoc/hevy-mcp), um projeto que integra dados de treinos do Hevy a clientes compatíveis com o Model Context Protocol (MCP).

A implementação original e seu histórico pertencem ao repositório de origem. Esta cópia acompanha o projeto upstream e pode ser utilizada para estudo e experimentação.

## Para que serve

O servidor MCP permite que clientes compatíveis consultem e, conforme as ferramentas e permissões disponíveis, interajam com informações do Hevy, como treinos, rotinas e exercícios.

## Tecnologias e recursos

Consulte a documentação oficial do projeto de origem para obter instruções atualizadas de instalação, configuração, ferramentas disponíveis, variáveis de ambiente e requisitos.

- Projeto original: [chrisdoc/hevy-mcp](https://github.com/chrisdoc/hevy-mcp)
- Licença: MIT (consulte o arquivo `LICENSE` deste repositório)
- Integração: Hevy API e clientes compatíveis com MCP

## Configuração

As instruções podem variar entre versões. Antes de executar, leia o README do projeto original e confirme as configurações exigidas pela versão presente neste fork. Nunca compartilhe sua chave de API ou inclua segredos em commits.
